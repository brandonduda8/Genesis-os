# Genesis OS Constitution

## Purpose

Genesis OS exists to coordinate intelligent workers that can plan, build, test, and improve software through a modular architecture.

## Principles

1. Stability before speed.
2. Build in small, testable milestones.
3. Prefer modular plugins over core modifications.
4. Every feature should include documentation.
5. Every feature should be testable.
6. Human approval is required before major architectural changes.
7. Preserve backwards compatibility whenever practical.
8. Workers should have one clear responsibility.
9. Athena is the architectural guide, not the final authority.
10. Genesis OS should continuously improve itself without losing simplicity.
